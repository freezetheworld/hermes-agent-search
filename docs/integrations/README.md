# MCP client integrations

Agent Search Stack is client-neutral. After running `scripts/install-mcp.sh`, use
the printed stdio executable in any MCP-compatible agent.

Examples:

- [Generic MCP / Claude Desktop / Cursor / Windsurf](generic-mcp.md)
- [Hermes Agent](hermes.md)

These integrations are optional. The HTTP API and Python SDK work without an MCP
client.
