# Upstream and attribution

Agent Search Stack is a derivative distribution of
[AgentSearch](https://github.com/brcrusoe72/agent-search), originally created by
Brian Crusoe and released under the MIT License.

The complete Git history is retained so authorship and provenance remain
auditable. The original MIT license is preserved in [`LICENSE`](LICENSE).

This distribution adds portable MCP packaging and operations, a deterministic
fallback CLI, localhost-only deployment defaults, URL-safety checks, and local
reliability fixes. It is independent of any specific agent framework or vendor.

Contributions should retain the upstream copyright and license notices.
